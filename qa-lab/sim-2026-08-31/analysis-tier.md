# 파워 티어표 vs 실측 (10,050판 시뮬레이션)

- 표본: `stats.json` — `gameCount=10050`, 티어 태그 있는 증강 116개 (SS+ 1, S+ 16, S 23, A 15, B 18, C 21, D 22)
- 기준선: 전체 평균순위 2.5 (4인 게임 구조적 값), 평균 우마오카 점수 1569.3
- 개별 증강 표본 SE는 대개 0.02~0.05, 표본 344판 미만인 항목 없음 — 다만 **SS+가 표본 1개(단색 세계)뿐**이라 SS+ 티어 자체의 검증은 판단 불가로 둔다.

## 2. 상관계수

- Pearson(티어등급, avgPlacement) = **-0.3774**
- Spearman(티어등급, avgPlacement) = **-0.4875**
- Pearson(티어등급, avgScore) = **0.4006**
- Spearman(티어등급, avgScore) = **0.4938**

(티어등급은 SS+=7 … D=1로 부호화. 순위는 낮을수록 좋으므로 음의 상관이 "티어가 높을수록 실제로 강하다"는 방향과 일치, 점수는 양의 상관이 같은 방향.)

해석: 상관은 **중간 정도(0.4~0.5대)**로, 티어표가 실측과 완전히 무관하지는 않지만 강한 예측력을 가진다고 보기도 어렵다. 스피어만이 피어슨보다 약간 높게 나오는 건 조커·등가교환·분열처럼 극단적 이상치가 순위상관을 덜 왜곡하기 때문으로 보인다. |r|<0.5는 "약한~중간" 수준의 연관으로 해석하는 것이 안전하며, 티어 하나만으로 실측 순위를 강하게 예측할 수 있다고 결론내리기는 어렵다.

## 4. avgScore(순위점) 기준 검증

점수는 avgPlacement보다 정보량이 많지만, `stats.json`에 증강별 점수 SE가 없어 순위처럼 정밀한 z-검정은 불가능하다. 대신 **티어 그룹 내 avgScore의 표준편차(SD)**를 기준으로 상대적 이탈을 보았다(엄밀한 유의성 검정이 아니라 그룹 내 상대적 크기 비교임을 명시).

## 요약

- **A/B 등급 순서 전도**: 실측 평균순위·점수 모두 A(2.509 / 1,831)가 B(2.469 / 2,536)보다 나쁘다. 티어표상 A>B이지만 실측은 반대.
- **SS+ 검증 불가**: 표본 1개(단색 세계)뿐이라 SS+ 티어 자체의 타당성은 판단 불가.
- **상관은 중간 수준**: Pearson -0.377 / Spearman -0.488 (순위 기준), Pearson 0.401 / Spearman 0.494 (점수 기준). 티어와 실측이 완전히 무관하지는 않으나 강한 예측력이라 보기엔 부족하다.
- **가장 뚜렷한 과소평가(낮은 티어, 높은 실측)**: D등급 승승장구(z=-10.52)·카르마(z=-10.45), B등급 기생충(z=-13.70)·비대칭(z=-8.19)·가불 인생(z=-6.78, 판수 380으로 SE 큼).
- **가장 뚜렷한 과대평가(높은 티어, 낮은 실측)**: S+등급 묵계(z=6.86)·왕의 징표(z=5.42)·개문선언(z=5.01, 판수 3,783으로 신뢰도 높음)·큰손(z=4.54), S등급 날치기(z=4.99)·무형화료(z=4.91).
- **조커(S+)는 티어표 최상위인 SS+보다도 실측 성능이 높다** — 순위 1.710, 점수 25,373으로 SS+ 단색 세계(2.140 / 12,944)를 크게 상회.
- 점수 기준 검증은 그룹 SE가 없어 순위 기준만큼 엄밀하지 않다는 한계가 있고, 특히 하위 이탈 쪽은 |z|<2로 대부분 판단 불가 수준이다. 다만 모 아니면 도처럼 순위로는 안 보이던 이탈이 점수로 드러나는 사례가 있어, 점수 지표가 순위 지표를 보완한다는 점은 확인된다.
