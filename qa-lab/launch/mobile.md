## 1. [P3] 컷인(리치 등) 스킵 버튼이 연출 도중 한 프레임 살짝 가려짐 — 재현 미확정

- 증상: tap.js 히트테스트에서 `button.prod-skip` 이 `div.table`·`div.prompt-timer-fill` 에 5점 중
  2점이 가려져 `3/5만 통과`로 잡혔다. 안정 상태(컷인 종료 후)에서 재검사하니 `blocked: 0`.
- 재현/근거: `__tapProbe()` 1회 호출 결과에서만 관측, 직후 재호출에서는 사라짐. 스크린샷으로
  당시 화면을 못 잡았다(호출 사이 프레임이 넘어감).
- 판정: **의심** — 컷인 진입 애니메이션의 과도기 한 프레임일 가능성이 높고(3/5는 여전히

  막히지 않는다"고 확인한 영역과 겹친다. 실사용 영향(스킵을 못 누르는 것)은 확인하지 못했다.
- 제안: 다음 라운드에서 재현 스크립트로 컷인 등장 순간을 연속 캡처해 실제로 클릭 실패가

## 6. 눈으로 본 판정 — 자동 측정이 못 잡는 것

375×700 · 360×640 · 390×760 · 430×830 · 667×375 · 740×360 · 844×390 · 932×430 스크린샷을
직접 보고 확인했다.

- **글자 잘림 / 대비**: 진행 중 확인한 모든 화면(로비, 증강 선택, 대국 중 4방향 점수판,
  내 손패, 상대 이름표, 빠른 토글, 액션 알약 라벨)에서 잘림·저대비 없음. 흰 배경 마작패 +
  어두운 펠트 배경 대비 양호. 증강 선택 카드 설명은 #428 수정대로 375×700 에서 온전히
  보인다(높이 고정 대신 `min-height` — 실측: 설명 텍스트 하단까지 잘리지 않고 노출됨).
- **손가락으로 가려지는 영역**: 액션 바·손패는 화면 하단에 있어 엄지 자연 위치와 겹치지만
  이건 마작 UI의 통상 배치이고, 조작 버튼 자체가 그 자리에 있어야 하는 것들(치·펑·론 등)이라
  가림 자체가 문제는 아니다. 별도의 위험 요소(예: 우측 하단에 실수로 눌리는 «론» 등)는
  찾지 못했다 — 액션 알약은 필요할 때만 나타나고 평시엔 자리를 비운다.
- **가로/세로 회전 중 전환**: 실제 orientation change 이벤트는 이 환경(에뮬레이션 리사이즈)
  에서 재현할 수 없었다 — `resize_window` 는 뷰포트 크기만 바꾸고 `orientationchange` 를
  내지 않는다(엔진 한계). `@container ui` 기반 반응형이라 이론상 리사이즈만으로도 즉시
  재계산되는 것은 위 표에서 확인했다(각 크기 전환마다 겹침 0). **실기 회전 애니메이션
  중간 프레임은 미검증**으로 남긴다(docs/45 도 §14 에서 같은 한계를 적어 두었다).
- **소프트 키보드**: 재현 불가(에뮬레이터가 실제 키보드를 안 띄운다). 로그인 폼 입력 필드는
  포커스 시 자동 스크롤이 되는지 코드상 `scrollIntoView` 류를 찾지 못했으나, 로그인 폼이
  화면 상단부에 있어 일반적인 소프트 키보드(화면 하단 40%)와 안 겹칠 가능성이 높다 — **의심**,
  실기 검증 필요.
- **iOS 세이프에어리어**: 코드상 `env(safe-area-inset-top)` 이 `--chrome-top` 계산에 들어가
  있음을 docs/43 §1-#3 에서 이미 확인했고, 이번 회귀에서 그 계산식(styles.css 아이콘 줄
  `top` 규칙)이 남아 있는 것을 grep 으로 확인했다. 에뮬레이터는 inset=0 이라 실측 불가 —
  **미검증**(docs/45 §14 와 동일한 한계).
- **스크롤 튐**: 대국 화면 자체는 스크롤이 없다(고정 레이아웃). 증강 선택 오버레이는
  세로로 스크롤되는데, 8개 뷰포트 중 스크롤 도중 레이아웃이 흔들리거나 카드가 겹치는 것은
  관측하지 못했다.
- **더블탭 확대**: 코드 확인 — `viewport` 메타 태그나 `touch-action` 설정을 별도로 안 봤다
  (범위 밖). 게임판 자체는 버튼투성이라 더블탭이 UI 액션(예: 손패 두 번 눌러 버리기)으로
  먼저 소비되는 구조라 브라우저 확대 제스처와 충돌할 가능성이 있으나 **직접 재현은 못했다**
  (에뮬레이션 환경은 핀치/더블탭 확대 제스처를 브라우저 레벨에서 다르게 처리한다). 미검증.
