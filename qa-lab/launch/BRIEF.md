## 보고 형식 (엄수)
`qa-lab/launch/<담당>.md` 에 쓴다. 항목마다:

```
### [P0|P1|P2|P3] 한 줄 제목
- 위치: packages/x/src/y.ts:123  (또는 재현한 화면/뷰포트)
- 증상: 사용자가 실제로 겪는 것. 추상적 "개선 여지" 금지.
- 재현/근거: 실행한 스크립트와 그 출력, 또는 코드 인용. 스크린샷 경로.
- 판정: 확정 / 의심
- 제안: 구체적 수정 방향 (파일·함수 단위)
```
심각도: **P0 출시 불가 · P1 출시 전 필수 · P2 있으면 좋음 · P3 기록만**.
맨 끝에 확정건 심각도순 요약 표. 그리고 «봤는데 문제 없었다»고 확인한 목록도 적어라 —
다음 라운드가 같은 곳을 다시 파지 않게.

## 규칙
- **추측 금지.** 실제로 돌려 보거나 코드를 인용한 것만 «확정». 나머지는 «의심».
- **이 단계는 조사·보고만이다. `packages/` 를 한 줄도 고치지 마라.** 수정은 다음 웨이브다.
- 없으면 없다고 써라. 억지로 채우지 마라. 5건 확정이 30건 추측보다 낫다.
- 다른 담당 파일(`qa-lab/launch/*.md`)을 덮어쓰지 마라. 네 파일만 쓴다.

## 환경 (필수 준수)
- 워크트리 루트: `~/majak/.claude/worktrees/game-launch-qa-plan-09cd26`. 여기서만 작업.
  `node_modules/@majak/*` 링크는 이미 걸려 있다.

    ~/majak/node_modules/.bin/tsx packages/server/src/index.ts &

- ⚠ **포트 3011 = 공개 서버.** 절대 건드리지 마라. `pkill -f` 금지 — 죽일 때는 **PID로만**.
- ⚠ `git checkout -- ` / `git restore` / `git stash` 금지 (미커밋 변경이 날아간다).
- 클라이언트 UI를 봐야 하면 `npm run dev:client` (vite) 대신
  `~/majak/node_modules/.bin/vite --port <배정vite포트>` 를 `packages/client` 에서 띄운다.
