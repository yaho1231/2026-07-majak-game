# 레이아웃 겹침 프로브

`probe.js` 는 **브라우저에 붙여서 쓰는** 한 파일짜리 검사기다. 겹치면 안 되는 그룹
(내 손패 · 내 이름표 줄 · 액션 바 · 중앙 보드 · 네 방향 점수판 · 상대 세 줄 · 구석 위젯)
끼리 실제 사각형이 얼마나 물리는지, 화면 밖으로 나갔는지, 상자를 넘쳤는지를 한 번에
돌려준다. 소스를 읽어서 추측하지 않고 **실제로 그려진 것**을 잰다.

## 쓰는 법

대국 화면을 띄운 탭의 콘솔(또는 자동화 도구)에서 파일 내용을 그대로 실행하면
`window.__layoutProbe` · `__qaSize` · `__qaRun` · `__qaEnter` 가 선다.

```js
__qaSize();   // 창 크기를 바꾼 직후 한 번 — 자동화 도구의 뷰포트 변경은 resize 를 안 낸다
__qaRun();    // 한 줄 요약 (배율 · 가상 뷰포트 · 패널 크기 · 겹침 목록)
```

`#qa` 해시로 열어 두면 `__qaEnter()` 가 로비 → 바로 한 판 → 증강 1장까지 자동으로 밟는다
(HMR 로 새로 고쳐져도 같은 자리로 돌아온다).

## 판정 기준 하나

중앙 패널이 **레이아웃 px 190 아래**로 내려가면 국 표시·도라·네 방향 점수판이 서로
올라탄다(152에서 확실히 깨진다). 그래서 `pL` 값을 먼저 본다 — 겹침 0건이어도 이 값이
190 근처면 다음 상태 하나에 깨진다는 뜻이다. 자세한 계산은
[docs/42_QA_RESPONSIVE_2026-08-24.md](../../docs/42_QA_RESPONSIVE_2026-08-24.md).
