# QA 4라운드 수정 지침

`qa-lab/round4/<담당>.md` 의 확정건을 실제로 고친다.

## 규칙
1. **자기 담당 파일만 만진다.** 다른 팀이 동시에 다른 파일을 고치고 있다. 배정 밖 파일은 건드리지 마라.
2. 고칠 때마다 **되돌리면 실제로 실패하는** 회귀 테스트를 남긴다. CSS·레이아웃처럼 테스트가 불가능한 건은
   그 사실을 수정 로그에 적는다.
3. **P0 → P1 → P2** 순. P3는 건너뛴다.
4. 설계 의도가 걸린 건(사용자가 일부러 뺀 것 등)은 고치지 말고 «판정 대기»로 남긴다.
5. 고치지 않기로 한 확정건은 이유를 적는다. 조용히 빠뜨리지 마라.
6. 끝나면 **자기 담당 테스트 파일 + 관련 패키지 타입체크**를 돌려 통과를 확인한다.
   (전체 `npm test` 는 8분 걸리므로 마지막에 오케스트레이터가 한 번만 돌린다.)
7. `qa-lab/round4/fix-<담당>.md` 에 **[항목] → [고친 방법] → [근거/테스트]** 표로 수정 로그를 남긴다.
