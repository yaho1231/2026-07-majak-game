# 48_AUGMENT_SYNERGY_QA — 증강 시너지 QA 4라운드 (2026-08-31)

Version : 1.0
Status : Active

**질문**: 설명과 구현 의도상 비슷하게 동작하거나 서로를 키워 줄 법한 증강을 2~4장 함께 들었을 때,
① 오류가 없는가 ② **각각 쓸 때보다 실제로 좋아지는가**.

카탈로그 113종을 8개 축으로 나눠 전담 QA 팀이 조사했다. 방법은 3라운드(docs/40)를 이어받되 한 단계
더 못 박았다 — **단독 A / 단독 B / A+B를 같은 시드·같은 장면에서 재서 비교한다.** 예측을 먼저 글로
적고, 다르면 원인을 소스에서 확인한다.

- 증거·재현 스크립트: `qa-lab/synergy4/<축>/` (축별 `report.md` + 스크립트)
- 조사 중 `packages/` 는 한 줄도 고치지 않았다.

## 이 라운드가 다시 확인한 것

**전수 스위프가 깨끗한 것은 «문제 없음»이 아니다.** 축별 실판 스위프를 다 합쳐 2,000판 이상을 돌렸고
크래시·훅 예외·불변식 위반은 사실상 0이었다. 그런데 아래 확정 결함 34건 중 구조 검사에 걸리는 것은
거의 없다 — 점수가 8,000에서 96,000이 되는 폭발조차 `augPoints`로 «정상 귀속»되어 드리프트 검사를
통과한다. 의미를 따로 재야 했던 이유가 이것이다.
