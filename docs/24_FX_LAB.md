# 24. 증강 연출 랩 (FX Lab) — 프로토타입

증강 하나하나에 어울리는 웹 연출을 **실제로 돌려보고 고르기 위한** 독립 페이지다.
게임 클라이언트(`packages/client/src/App.tsx`)와 완전히 분리돼 있고, 빌드에 포함되지
않는 정적 파일 4개로만 이루어진다. 실패해도 게임에 영향이 없고, 마음에 드는 연출만
골라 클라이언트로 옮기면 된다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `packages/client/public/fx-lab.html` | 무대 마크업 + 공용 SVG 필터(`#fInk` `#fGoo` `#fFog`) |
| `packages/client/public/fx-lab.css` | 무대·패·카드 스타일 (게임과 같은 색 언어) |
| `packages/client/public/fx-core.js` | 런타임: 좌표계, WAAPI 래퍼, 캔버스 루프, 합성음, 공용 조각 |
| `packages/client/public/fx-lab.js` | 연출 16종 정의 + UI 배선 |

패 이미지는 게임과 같은 `public/tiles/*.png` 를 그대로 쓴다.

## 실행

클라이언트 dev 서버가 떠 있으면 <http://localhost:5173/fx-lab.html> 로 바로 열린다.

```bash
npm run dev:client
```

정적 파일뿐이라 `node_modules` 없는 워크트리에서도 아무 파일 서버로 열 수 있다.

```bash
python3 -m http.server 5188 --directory packages/client/public
```

조작: 왼쪽에서 연출 클릭 · `Space` 다시 재생 · `↑↓` 이전/다음 · **속도를 0.25× 로 낮추면
기법이 눈에 보인다**(연출을 고를 때 이게 제일 유용하다).

## 설계 결정 두 가지

**1000×625 고정 좌표계.** 무대는 항상 1000×625 이고 화면 맞춤은 `.stage` 의 `scale()`
로만 한다. 캔버스 입자 물리와 CSS 위치가 같은 단위를 쓰게 하려는 것 — 이게 없으면
입자 궤적이 화면 크기마다 달라진다. 요소 좌표는 `sRect()` 로 실측해서 쓴다.

**모든 애니메이션은 WAAPI(`element.animate`).** 살아있는 애니메이션을 집합으로 들고
있다가 `playbackRate` 를 일괄 적용해 슬로우모션을 만든다. CSS `@keyframes` 로는 이게
안 된다. 연출 사이 초기화는 `resetStage()` 가 무대를 통째로 다시 세워서 정리 버그를
원천 차단한다.

## 연출 16종

### 3D 변환 + 물리

| 증강 | 연출 | 기법 |
| --- | --- | --- |
| 밥상 뒤엎기 | 판이 기울고 손패 13장이 날아간 뒤 새 손이 깔린다 | `perspective` 3D 틸트 + DOM→**캔버스 스프라이트 인계** 후 중력·회전 물리 |
| 뒤집힌 모래시계 | 모래가 거꾸로 흐르고 진행 순서가 반전된다 | 오버슈트 3D 뒤집기 + **역중력 입자** + 호살표 `stroke-dashoffset` 방향 반전 |
| 오픈 리치 | 손패를 눕혀 공개하고 사본이 세 상대에게 날아간다 | `rotateX` 스태거 플립 + 금빛 글레어 스윕 + 고스트 사본 |

### 캔버스 입자

| 증강 | 연출 | 기법 |
| --- | --- | --- |
| 개벽 | 판이 빛으로 흩어져 중앙에 모이고 새 판이 열린다 | 모든 패 위치 실측 → 수백 입자 내폭 → 섬광 → 재배치 (`lighter` 합성) |
| 마작의 거신병 | 거신이 일어서고 빛의 기둥이 판을 관통한다 | SVG 실루엣 + `drop-shadow` 발광, 수렴 입자, additive 그라디언트 빔 |
| 일확천금 | 슬롯 릴이 돌고 동전이 쏟아진다 | 릴 감속 이징 + 동전 물리(중력·바닥 반발·마찰) + 숫자 롤업 |

### 마스크 · 스캔

| 증강 | 연출 | 기법 |
| --- | --- | --- |
| 투시 | 스캔 바가 지나간 자리에 상대 손패가 드러난다 | 네거티브 필터 사본 레이어 + **`clip-path inset` 밴드 이동** |
| 천리안 | 레이더가 회전하며 텐파이한 상대에 핑을 띄운다 | `conic-gradient` 회전 스윕 + 좌석 각도에 맞춘 핑 링 |
| 스파이 | 패 1종을 몰래 찍는다 — 나만 보이는 표식 | SVG 레티클 락온 + **구멍 뚫린 마스크 비네트** |

### SVG 필터

| 증강 | 연출 | 기법 |
| --- | --- | --- |
| 염색 | 잉크가 떨어져 손패 색이 번져 물든다 | `feTurbulence`+`feDisplacementMap` 로 찢은 `clip-path` 번짐 |
| 분열 | 패 한 장이 세포분열해 두 장이 된다 | **gooey 필터**(`feGaussianBlur`→`feColorMatrix` 알파 임계)로 '목'을 만든다 |
| 박무 | 안개가 바닥을 덮어 버림패를 가린다 | 애니메이션되는 `feTurbulence` 3겹 + `backdrop-filter blur` |

### 파괴 · 임팩트

| 증강 | 연출 | 기법 |
| --- | --- | --- |
| 무장해제 | 상대 증강 카드가 금이 가고 부서져 잠긴다 | 카드 N개 복제 + **`clip-path polygon` 삼각 팬 파편** + 균열 필기 |
| 핏빛 계약 | 계약서에 낙관이 찍히고 피가 흘러내린다 | `stroke-dashoffset` 서명 + 하드 이징 슬램 + `multiply` 핏방울 |
| 시간 정지 | 내 좌석만 색이 남고 판 전체가 멈춘다 | `backdrop-filter grayscale` + **radial mask 구멍** + 먼지 급정지 |
| 무덤 도굴 | 왕패에서 패를 파내 손으로 끌어온다 | 3D 상승 + 흙먼지 + **베지에 궤적**(양쪽 좌표 실측) |

## 연출을 고를 때 본 것

프로토타입을 돌려보며 반복해서 확인된 것들 — 클라이언트로 옮길 때도 같이 가져갈 만하다.

- **연출과 상태 변화를 같은 타임라인에 붙인다.** 염색은 번짐이 도착한 타일의 이미지를
  실제로 교체하고, 분열은 끝나면 손패가 정말 14장이 된다. 화면만 번쩍이고 상태가 그대로면
  "무슨 일이 일어났는지" 가 몸에 남지 않는다.
- **강한 연출은 길이가 아니라 단계로 무게를 만든다.** 거신병은 예고(재) → 등장 → 충전 →
  발사 → 여운 5단이다. 같은 시간을 한 덩어리로 쓰면 그냥 시끄럽다.
- **정보 비대칭은 색으로 말한다.** 시간 정지는 판 전체를 회색으로 만들고 내 손패만
  마스크로 구멍을 뚫어 색을 남긴다. 규칙 설명 없이 "나만 움직인다" 가 전달된다.
- **감지는 순차적이어야 정보가 된다.** 천리안은 스윕이 좌석 각도를 지날 때 핑이 뜬다.
  동시에 다 뜨면 정보가 아니라 장식이다.
- **대칭 도형은 뒤집어도 안 뒤집힌 것처럼 보인다.** 모래시계는 위·아래 캡 폭을 다르게
  둬서 회전을 눈에 보이게 만들었다.
- **수십 장을 움직일 땐 DOM 을 버리고 캔버스로 넘긴다.** 밥상 뒤엎기·개벽이 그렇다.
  개별 DOM 트랜스폼으로는 60fps 가 안 나온다.

## 클라이언트로 옮길 때

`packages/client/src/styles.css` 에는 이미 70여 개 `@keyframes` 와 컷인·리치·역만 연출이
있다. 랩의 연출 중 **기존 어휘로 안 되는 것**만 옮기면 된다 — 캔버스 입자(밥상 뒤엎기,
개벽, 거신병, 일확천금), SVG 필터(염색, 분열, 박무), `clip-path` 파편·밴드(무장해제, 투시),
`backdrop-filter` 마스크(시간 정지).

옮길 때 랩과 달라지는 점:

- 좌표는 `sRect()` 대신 React `ref` + `getBoundingClientRect` 로 잡는다. 실측은 유지해야
  한다 — 하드코딩하면 모바일 레이아웃에서 조용히 깨진다.
- 캔버스 루프는 하나만 두고 연출들이 draw hook 을 등록하는 구조(`fx-core.js` 와 동일)가
  React 에서도 그대로 쓸 수 있다. 연출마다 캔버스를 만들면 안 된다.
- 합성음은 `src/sfx.ts` 에 이미 훨씬 잘 만들어진 게 있으니 랩의 신스는 버리고 그쪽에
  연출별 큐를 추가한다.
- 슬로우모션 배율은 랩 전용이다. 대신 설정의 연출 on/off 와 `prefers-reduced-motion`
  대응이 필요하다.
