# 17. 디자인 발주 명세서 (외주 디자이너용)

> **목적** — MAJAK(리치마작 × 증강) 서비스의 **모든 그래픽 에셋**을 한 번에 발주한다.
> **기준** — 2026-07-22 현재 구현된 클라이언트 실물(`packages/client/src/App.tsx` 7,540줄 / `styles.css` 5,914줄) 전수 조사.
> **원칙** — ① 무료 소재로 해결 가능한 것은 **발주 제외**(§2) ② 나머지는 화면 단위로 하나도 빠짐없이 ③ 증강은 개별 명세(§11)까지.
>
> 현재 프로젝트의 **실제 이미지 에셋은 마작패 PNG 37장이 전부**다. 그 외 전 화면이 CSS 그라디언트·box-shadow·이모지로 그려져 있다. 즉 이 문서는 "일부 교체"가 아니라 **비주얼 전면 구축** 발주다.

# 1. 디자인 컨셉 — 방향 설정

## 1.1 레퍼런스 분석: 무엇이 팔리는가

| 레퍼런스 | 팔린 이유 | 우리가 가져올 것 | 가져오면 안 될 것 |
| --- | --- | --- | --- |
| **작혼(雀魂)** | 마작이라는 노잼 장르에 **캐릭터·연출·수집욕**을 얹음. 리치 컷인 하나로 유입. | 연출 밀도, 프리미엄 마감, "패 하나 버릴 때마다 손맛" | 캐릭터 가챠 BM(우리는 인력·비용 불가), 과한 모에 톤 |
| **Balatro** | **정보 밀도 높은 카드 UI**로 "조합이 터지는 순간"을 시각화. 픽셀/CRT 톤으로 저비용 고임팩트. | 증강 카드의 정보 구조, 숫자가 튀는 쾌감, 통일된 저비용 아트 시스템 | 픽셀아트 톤(마작패와 충돌) |
| **천봉(天鳳)** | 극단적 기능주의. 코어 유저 신뢰. | 판독성 우선, 정보 은폐 없음 | 무미건조한 룩 (우리 타깃 아님) |
| **하스스톤** | 카드 발동 순간 **물리적 무게감**(먼지·충격·소리) | 증강 발동의 촉감, 카드 프레임 언어 | 판타지 세계관 |

**결론** — 우리 셀링 포인트는 캐릭터가 아니라 **"증강이 마작 규칙을 부수는 순간"**이다.
작혼의 마감 품질 × Balatro의 조합 쾌감을 **캐릭터 없이** 달성해야 한다. 즉 **연출과 카드 아트에 예산을 몰고, 인물 일러스트는 0**으로 간다.

## 1.2 컨셉 후보 3안

### A안. 「심야 밀실(深夜密室)」 — 네오누아르 ★추천

> 도시 어딘가, 규칙이 통하지 않는 비공식 마작장. 초자연적인 힘(증강)이 판을 뒤튼다.

- **톤**: 어두운 실내, 단일 광원(테이블 위 펜던트 조명), 짙은 그림자, 담배 연기 같은 부유물
- **재질**: 짙은 녹색/암청색 펠트, 검게 그을린 원목 프레임, 황동(brass) 금속, 유리
- **증강 표현**: 물리 세계에 균열이 가는 **초자연 광선** — 번개·홀로그램·글리치
- **장점**: 현재 팔레트(심해 블루 + 금)와 연속성이 있어 **기존 구현을 살릴 수 있다**. 캐릭터 없이도 고급스럽다. 증강의 "초자연" 컨셉(52차 확정)과 정확히 맞는다. 마작패 오리지널 디자인의 자유도가 높다.
- **단점**: 어두운 톤은 썸네일·스토어 이미지에서 눈에 덜 띈다 → **증강 컷인의 채도로 보완**

### B안. 「화투방 · 한국형 레트로」

> 90년대 한국 기원(棋院)·화투방 감성. 형광등, 초록 매트, 스테인리스 재떨이.

- **장점**: 국내 타깃에 정서적 친밀감, 차별화 확실
- **단점**: 글로벌 확장 불가, 마작(일본)과 화투(한국)의 문화 충돌, "싸구려"로 읽힐 위험이 큼

### C안. 「수묵 · 동양 미니멀」

> 먹과 여백, 붉은 낙관 도장, 화지(和紙) 질감.

- **장점**: 저비용 고급감, 역 스탬프·캘리그래피와 상성 최고, 확장성 좋음
- **단점**: **증강의 도파민과 정면 충돌**. 차분함이 컨셉인데 우리는 "번쩍이는 순간"을 팔아야 한다.

> **채택: A안(심야 밀실)을 뼈대로, C안의 서예·낙관 요소를 "화료·역 판정" 영역에 국소 이식.**
> 즉 **평시에는 누아르, 화료·역만 순간에만 수묵 캘리그래피가 터진다.** 대비가 곧 도파민이다.

## 1.3 확정 아트 디렉션 (A안 상세)

### 색

```
[베이스 — 화면의 80%]
  탁자 펠트     #14352E ~ #0E241F   (짙은 녹색. 현재 블루에서 이동 제안 / 유지도 가능)
  또는 현행 유지 #12283F ~ #0A1826  (심해 블루)
  원목 프레임    #3A2418 ~ #1C1009
  패널 유리      rgba(10,22,36,.88)

[액센트 — 화면의 15%]
  황동 금       #D6B25E / #FFD76A      (기존 유지 — 브랜드 색)
  경고 적       #A33327 / #FF4A5E      (친·론·리치)

[증강 — 화면의 5%, 순간에만]
  프리즘 보라    #B07EF2 / #CFA9FF
  + 카테고리 8색 (§6.2, 코드 고정값이므로 변경 시 별도 협의)
```

- **원칙**: 평시 화면에서 채도 높은 색은 **금색뿐**. 증강이 발동할 때만 카테고리 색이 폭발한다.
- 다크 배경(#0A1826) 위 검수를 기본으로 한다. 흰 배경 목업 금지.

### 재질(머티리얼) 3종만 쓴다

1. **펠트/천** — 탁자, 배경. 미세 노이즈 + 부드러운 vignette
2. **황동/금속** — 프레임, 버튼, 리치봉. 상단 하이라이트 + 하단 반사
3. **유리/홀로그램** — 패널, 증강. 반투명 + 굴절 + 스캔라인

> 재질을 3종으로 묶는 것이 통일감의 핵심이다. 새 요소는 반드시 이 셋 중 하나에 속해야 한다.

### 조명

- **단일 광원, 위에서 아래로.** 모든 요소의 하이라이트는 위, 그림자는 아래(`inset 0 -3px`가 이미 그 규칙).
- 중앙(보드)이 가장 밝고 화면 가장자리로 갈수록 어두워진다(vignette).
- 증강 발동 시에만 **하단/측면 역광**이 들어온다 → "규칙이 뒤집혔다"는 신호.

### 타이포

- 본문: Pretendard (무료, 발주 제외)
- **숫자**: 점수·판수 전용 **비트맵/커스텀 숫자 세트 발주** — 점수판 느낌의 핵심 (§5.9)
- **캘리그래피**: 화 료 / 유 국 / 리 치 / 론 / 쯔모 / 역만 등 **11종만 손글씨 이미지**로 (§7.4)
- 그 외는 전부 시스템 폰트. 캘리그래피 남발 금지.

### 모션 언어 (에셋이 아니라 규칙 — 디자이너가 스펙으로 제출)

| 종류 | 지속 | 성격 |
| --- | --- | --- |
| 타패·후로 | 80~200ms | **타격**. 스쿼시&스트레치, 먼지, 흔들림 |
| 증강 발동 | 150~300ms | **초자연**. 섬광이 스치듯, 흔들림 없음, 스캔라인 |
| 화료·역만 | 600~2000ms | **의식**. 암전 → 캘리그래피 → 도장 → 숫자 롤업 |
| UI 전환 | 120~180ms | **무감정**. ease-out, 장식 없음 |

> ⚠️ 이미 확정된 규약: **증강 연출에 shake·충격파를 쓰지 말 것.** 후로(타악)와 증강(초자연)은 음색도 연출도 계열이 분리돼 있다.

### 캐릭터 정책

**인물 일러스트 없음.** 대신 4개 좌석에 **"패(牌) 문장(紋章)" 아바타** — 방위(東南西北)를 모티프로 한 추상 엠블럼(§10.1). 인건비 대비 효율이 압도적이고, 톤도 유지된다.

## 1.4 디자인 원칙 5조 (디자이너가 지켜야 할 룰)

1. **17px에서 읽히지 않으면 실패다.** 마작패·아이콘은 극소 크기에서 먼저 검수한다.
2. **평시는 조용히, 순간은 과하게.** 상시 노출 요소에 애니메이션·발광을 넣지 않는다.
3. **정보는 절대 가리지 않는다.** 장식이 패·점수·차례 표시를 덮으면 탈락.
4. **재질 3종·조명 1방향을 벗어나지 않는다.**
5. **모든 상태에 시각 단서를 준다.** 잠김·봉인·불가는 회색 처리만으로 끝내지 말 것(과거 "패가 클릭이 안 된다" 문의가 실제로 발생했다).

# 3. [A] 마작패 세트 — **최우선 (저작권 교체)**

현재 `packages/client/public/tiles/*.png` = **80×129px PNG 37장**, 출처 불명. 전량 오리지널 재제작.

## 3.1 앞면 37종

| 그룹 | 수 | 파일명 |
| --- | --- | --- |
| 만수(萬) 1~9 | 9 | `1m.png` … `9m.png` |
| 통수(筒) 1~9 | 9 | `1p.png` … `9p.png` |
| 삭수(索) 1~9 | 9 | `1s.png` … `9s.png` |
| 풍패 동·남·서·북 | 4 | `1z` `2z` `3z` `4z` |
| 삼원패 백·발·중 | 3 | `5z` `6z` `7z` |
| 적도라 5 | 3 | `0m` `0p` `0s` |

**파일명은 코드가 직접 참조하므로 절대 변경 불가.**

## 3.2 필수 제약 (계약서에 명시)

- **정면 정투영(문양 기준).** 판·평면은 기울이지 않는다(원근 없음). 단 입체감을 위해 **패마다 방향별 측면 두께 4종(상/하/좌/우)**을 둔다 — 앞면 문양은 이 스펙 그대로, 두께 변형만 추가. 규칙·발주 형태는 [18 §10](18_UI_REDESIGN_BRIEF.md) 참조.
- **투명 배경 PNG.** 패 몸통(아이보리 `#F8F5EC` + 라운드 5~7px + `inset 0 -3px` 그림자)은 CSS가 그린다 → **인쇄면(문양)만 납품**하는 방식으로 통일. (몸통 포함 방식으로 바꾸려면 사전 협의)
- **실사용 최소 크기 17px 폭.** 아래가 실제 사용 크기 전량이다:

| 용도 | 폭 |
| --- | --- |
| 증강 정보 패널 미니 | **17px** |
| 미니 타일 기본 | 25px |
| 대기 툴팁 | 27px |
| 대기 뱃지 | 28px |
| 오픈리치 뱃지 | 34px |
| 결과 화면 | 24~34px |
| 후로 패 | 38~52px |
| 상대 뒷면 | 38~50px |
| 내 손패 | 52~84px (16장 손패는 40~64px) |

  → **1s~9s(대나무)와 1m~9m(한자)가 17px에서 구분돼야 한다.** 획 굵기 최소 1.5px 유지, 내부 여백 축소, 삭수는 대나무 개수보다 **실루엣 차이**로 설계할 것.

- **⚠️ 종횡비가 현재 4종으로 갈려 있다** — 손패 1:1.6 / 바닥 1:1.5 / 후로 1:1.5 / 상대뒷면 1:1.36. 앞면 PNG 하나를 늘려 쓰는 중.
  → **디자이너가 1:1.5로 통일 제안 + 각 위치별 크롭/패딩 규칙을 스펙으로 제출**할 것. (코드 수정은 우리가 함)
- 색맹 대응: 적도라(`0m/0p/0s`)를 **빨강만으로 구분하지 말 것.** 외곽선·점 등 형태 단서 병기.

2. **저작재산권 전부 양도** + **상업적 이용 및 2차 수정 권리** 확보. (증강은 계속 추가·수정되므로 2차 수정권이 없으면 무의미하다.)
3. 사용 폰트·텍스처·브러시의 **상업 라이선스 목록 제출**. AI 생성물 사용 시 사전 고지 의무.

## 12.2 파일

- **SVG 원본**(레이어 유지, 텍스트 아웃라인화) + **PNG @1x/@2x**
- 원본 작업 파일(Figma 우선, AI/PSD 가능)
- 배경 **투명**, 다크(#0A1826~#2D5A80) 위 검수
- 애니메이션 소재는 **스프라이트 시트 + JSON** 또는 **APNG/WebP**. Lottie는 사전 협의(런타임 부담)

## 12.3 네이밍

- 마작패·증강은 **본 문서의 id 그대로** (코드가 직접 참조)
