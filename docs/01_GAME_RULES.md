# 01_GAME_RULES
Version : 1.0
Status : Active
Last Updated : 2026-07-15

이 문서는 **기본 리치마작 룰의 단일 정의**다.
여기 적힌 모든 값은 RuleRegistry의 **base 값**이 되며,
증강은 이 값들에 Modifier를 붙여 변경·추가·무효화할 수 있다.

표기 규칙: 각 항목 옆의 `code` 는 RuleRegistry의 규칙 키다.
키가 아직 없는 항목은 구현 시점에 키를 부여하고 이 문서를 갱신한다.

# 1. 기본 세팅 (2026-07-15 확정)

| 항목 | 값 | 규칙 키 |
|------|-----|---------|
| 인원 | 4인 | `game.playerCount` |
| 길이 | 반장전 (동장 4국 + 남장 4국, 연장 있음) | `game.length` |
| 시작 점수 | 25000 | `score.start` |
| 반환 기준 | 30000 (서입 종국 판정에만 사용) | `score.return` |
| 우마 | +15 / +5 / −5 / −15 | `score.uma` |
| 오카 | 없음 (순수 우마 제로섬) | `score.oka` |
| 최종 순위 점수 | (최종 점수 − 25000) / 1000 + 우마 | — |
| 동점 처리 | 기가(起家)에 가까운 순서가 상위 | `score.tieBreak` |

## 종국 조건

- 남 4국 종료 시 종국. 단 30000점 이상이 없으면 서장(西入)으로 연장, 도달 시 즉시 종국 `game.extension`
- 누군가 0점 미만이 되면 즉시 종국 (도비 종료) `game.bust`

# 2. 패 구성

| 항목 | 값 | 규칙 키 |
|------|-----|---------|
| 총 패 수 | 136장 — 만·통·삭 1~9 각 4장 + 자패 7종(동남서북백발중) 각 4장 | `tiles.set` |
| 적도라 | 3장 — 5만·5통·5삭 각 1장을 붉은 5로 대체. 도라 +1 취급 | `tiles.redDora` |
| 왕패 | 시작 14장 (영상패 4 + 도라/뒷도라 표시패 10). **깡으로 영상패를 뽑으면 보충 없이 줄어든다** — 07 §2 | `wall.deadWall` |
| 도라 표시패 | 개국 시 1장 공개. 깡마다 새로운 도라 1장 추가 공개 | `dora.indicators` |
| 뒷도라 | 리치 화료 시에만 적용 | `dora.ura` |

# 3. 진행

- 배패: 각자 13장, 친(동가)부터 쯔모. `hand.startSize`
- 턴: 쯔모 → (선택) 깡/쯔모화료 → 1장 버림. 반시계 방향 진행.
- 유효 패산이 소진되면 황패유국 (왕패 14장은 남김). `wall.exhaustDraw`

## 후로 (울기)

| 종류 | 조건 | 규칙 키 |
|------|------|---------|
| 치 | 상가(왼쪽)의 버림패로만 슌쯔 완성 | `call.chi` |
| 펑 | 아무 가의 버림패로 커쯔 완성 | `call.pon` |
| 대명깡 / 가깡 / 안깡 | 표준 규칙. 깡 후 영상패 쯔모(**소모 — 패산에서 보충하지 않는다**), 새로운 도라 공개 | `call.kan` |
| 우선순위 | 론 > 펑·깡 > 치 | `call.priority` |
| 가깡 도중 론 | 창깡 인정 (국사무쌍은 안깡에도 창깡 가능) | `call.chankan` |

# 4. 리치

| 항목 | 값 | 규칙 키 |
|------|-----|---------|

| 리치 후 | 화료패가 아니면 자동 버림(손 바꾸기 불가), 안깡은 대기 불변일 때만 허용 | `riichi.locked` |

# 5. 화료

- 론 / 쯔모. **역이 1개 이상 있어야 화료 가능** (도라는 역이 아니다). `win.requiresYaku`
- 더블론 인정. 트리플론은 유국. `win.multiRon`
- 후리텐: 자기 버림패에 화료패가 있으면 론 불가 (쯔모는 가능). 순후리텐·리치후리텐 표준. `win.furiten`

## 도중유국

| 종류 | 채용 | 규칙 키 |
|------|------|---------|
| 구종구패 | O (선택 유국) | `abort.kyuushu` |
| 사풍연타 | O | `abort.suufonrenda` |
| 사깡유국 | O (2인 이상이 4깡) | `abort.suukan` |
| 사인리치 | O | `abort.suucha` |
| 트리플론 | O (유국 처리) | `win.multiRon` |

## 황패유국

- 텐파이 공개, 노텐 벌부 3000점 (텐파이자에게 분배). `draw.notenPenalty`
- 친이 텐파이면 연친, 노텐이면 친 이동. `dealer.continue`
- 연장 1본당 화료 점수 +300 (론: 방총자 부담, 쯔모: 100점씩). `honba.value`

# 7. 점수 계산

- 부(符) 계산: 표준 (기본 20부 + 대기·멘쯔·머리 가산, 10부 단위 올림. 치또이 25부, 핑후쯔모 20부, 후로핑후형 론 30부).
- 판수별 점수: 표준표 사용. 만관 미만은 부×2^(판+2) 기반, 자/친 배율 1:1.5.

| 판수 | 자(론/쯔모) | 친(론/쯔모) |
|------|-------------|-------------|
| ~4판 | 계산식 | 계산식 |
| 만관 (4판 40부+, 5판) | 8000 | 12000 |
| 하네만 (6~7판) | 12000 | 18000 |
| 배만 (8~10판) | 16000 | 24000 |
| 삼배만 (11~12판) | 24000 | 36000 |
| 역만 (13판+ / 역만역) | 32000 | 48000 |

- 절상 만관(키리아게) 없음: 4판 30부 = 7700/11600 그대로. `score.kiriage`
- 셈수 판수(카조에) 역만 인정 (13판 이상). `score.kazoeYakuman`

# 8. 증강 획득 스케줄 (2026-08-04 수정 확정)

> 차터 초안의 "매 국 시작 1회 + 13순 1회" → "게임 시작 + 남장 진입 총 2개"를 거쳐
> 아래로 **변경**되었다.

- **지정된 국에 첫 진입할 때 1개씩** 지급한다. 본장 연장으로 같은 국이 여러 번 열려도
  그 국의 드래프트는 **첫 진입 때 한 번만** 열린다.
  - **동풍전: 동1국 · 동3국 · 동4국 — 총 3개.**
  - **반장전: 동1국 · 동3국 · 남1국 · 남3국 — 총 4개.**
- 방식: 각 플레이어에게 개인별 랜덤 3개 제시 → 1개 선택. 선택 결과는 전원 공개한다.
- 스케줄 키(`HanchanConfig.draftSchedules`):
  동풍전 `["gameStart", "eastThird", "eastFourth"]`,
  반장전 `["gameStart", "eastThird", "southEntry", "southThird"]`.
  `gameStart`가 곧 동1국 진입이다.
- 스케줄 자체가 설정이므로, "매 국 드래프트" 같은 변형 모드는 설정 변경만으로 가능하다.

설계 함의: 지급 수가 늘어 **한 사람이 3~4개(도박사 계열이 겹치면 그 이상)를 동시에 굴린다** —
증강 간 상호작용·중첩이 실전 기본값이다. 밸런스는 10_AUGMENT_SYSTEM에서 설계할 것.

# 9. 미세 룰 (기본값, 필요 시 조정)

- 책임지불(파오): 대삼원·대사희 확정시킨 후로에 적용 `score.pao`
- 깡 도라: 기본 즉시 공개. 변형 룰에서 깡 후 버림 뒤 공개 가능 (`dora.kanTiming = "beforeRinshan" | "afterDiscard"`)
- 안깡 국사 론: 허용 (창깡 항목 참조)
- 유국 시 리치봉: 이월 (반장 종료 시 남으면 1위 획득) `riichi.potEndGame`
