## 1. 진단 — 반복되는 AI 버릇 6가지

가장 많은 것부터. 각 항목의 «일괄 처리» 여부가 작업량을 정한다.

### 1-1. 줄표(—) 부연 「X — Y」 (약 400곳, 전 영역)
가장 확실한 신호. 결과·부연·이유·다음 행동을 줄표 하나로 이어 붙인다.
- `서버와 연결이 끊겼습니다 — 다시 연결되면 눌러 주세요` → `서버와 연결이 끊겼습니다. 다시 연결된 뒤에 눌러 주세요.`
- `공유 링크를 내렸습니다 — 기존 링크는 더 이상 열리지 않습니다` → `공유를 해제했습니다. 기존 링크는 더 이상 열리지 않습니다.`
- 버튼 라벨 `개벽 — 발동` → `개벽 발동`, 상태 라벨 `토비 — …` → `토비: …`

규칙: 문장이면 **마침표로 끊어 두 문장**. 라벨·제목이면 **공백 또는 콜론**. 이유가 뒤에 오면 순서를 바꾼다(`가입 코드를 입력해 주세요 — 이 서버는 초대제입니다` → `이 서버는 초대제입니다. 가입 코드를 입력해 주세요.`). 코드에서 `" — "`로 join하는 곳(App.tsx 6356·7487, conflictNotes 67·69)은 `": "`·`", "`로 바꾼다.
저장소 전체 `grep -n " — " packages/*/src` 로 잔여를 확인할 수 있다 — **일괄 치환은 불가**(라벨/문장/제목마다 처리가 다르다). 파일 단위로 손으로 간다.

### 1-2. 기호가 문장을 대신함 (약 250곳)
`«»`·`「」` 강조 인용(튜토리얼 30곳, 관전 도크, 안내문), `→ ↔ ± × = +` 수식 표기, `⚠` 경고 머리, `✓ ✦ 🎲 🎓` 문장 접두 이모지, `·` 4개 이상 나열.
- `«연금술사»는 손패의 수패 한 장을 숫자 ±1로 바꿉니다` → `연금술사는 손패의 수패 한 장을 숫자 1 위나 아래로 바꿉니다`
- `넘긴 패 → 받은 패` → `왼쪽이 넘긴 패, 오른쪽이 받은 패입니다`
- `⚠ 적도라(빨간 5)를 옮기면 빨간색은 사라진다.` → `적도라(빨간 5)를 옮기면 빨간색은 사라진다.`

규칙: «»는 지우고 이어 쓴다(버튼 이름은 `론 버튼`처럼 '버튼'을 붙임). 화살표·등호·±는 조사로 푼다. ⚠는 지운다. 문장 앞 기호는 뺀다(칩·뱃지의 아이콘 🔒♻🕐✦는 화면 표식이라 남긴다 — 별도 CSS 분리 과제). 가운뎃점은 2~3개 병렬까지만, 그 이상은 쉼표.
`«`·`»`·`⚠`·`↔`·` → `는 grep으로 전부 잡히므로 **반자동 처리 가능**.

### 1-3. 비유·문어 동사와 압축 부사 (약 540곳)
규칙 설명에 소설 동사를 쓴다: 세우다(일시정지)·태우다/재다/값하다(계산)·잠기다/열리다(고정/해제)·켜다(사용)·심다·물들다·터지다·서다·붙다·문다·돌다·갈아타다·얹다. 부사: 내내·통째로·그대로·영영·곧·한 번도.
- `관리자가 판을 세웠습니다` → `관리자가 게임을 일시정지했습니다` (App.tsx 5089·7681·22048, RoomManager 2301 — 4곳 동일)
- `그 리치는 2판으로 값한다` → `그 리치를 2판으로 취급한다`
- `리치 뒤 오름패를 넘겨 이 국 내내 후리텐입니다` → `리치 후 오름패를 론하지 않아 이 국이 끝날 때까지 후리텐입니다`

규칙: 게임 UI가 쓰는 직설 동사로 — 일시정지·재개·계산·고정·해제·사용·발동·표시·적용·취소·복구. '그대로'는 본뜻(바꾸지 않고)일 때만 남긴다.
치환표(부록 §패턴에서 정리): `판을 세우다→일시정지`, `값하다→계산하다/취급하다`, `켜다(증강)→사용하다/발동하다`, `잠기다(손패)→고정되다`, `열리다(기능)→사용할 수 있다`, `열리다(정보)→공개되다`, `내내→끝날 때까지/동안`, `통째로→전부/모두`, `아무것도 얹히지 않는다→추가 판이 없다`.

### 1-4. '쓰다'·'방'·'판'·'전원'·'손' — 사용자 예시와 같은 유형 (약 250곳)
- `쓸 수 없다`(21곳, 증강 도감)·`써 봅시다`·`쓰는 법` → **사용하다**
- `판`이 게임 전체를 뜻하는 자리(`한 판 두고 나면`, `이 판을 볼 수 있는 링크`, `곧 판에 반영됩니다`) → **게임**. 한 국을 뜻하면 **국**. 역의 단위 '판(飜)'과 '판 길이'(대기실 라벨 짝)는 유지.
- `전원`(증강 도감 27곳, `전원 공개`·`전원의 모든 결정`) → **모두에게 / 모든 참가자**
- `손`(손패 축약: `손이 잠기다`, `손으로 올라온다`) → **손패**
- `부르다`(친구 초대, 7곳) → 버튼 이름에 맞춰 **초대하다**
- `지금 비밀번호`(클라 12006·12023, 서버 SiteDb 835) → **현재 비밀번호**
- `방`은 방 코드·방장·대기실처럼 **실제 로비 용어인 곳은 유지**. 게임 진행을 뜻할 때만 '게임'.

`쓸 수 없`·`전원`·`손이 `·`손으로 `는 grep 후 **문맥 보고 치환**(반자동).

### 1-5. 괄호 보충 연쇄와 명사 종결 (약 250곳)
`(무늬 유지, 1↔9 순환 없음)`, `(판은 계속됩니다)`, `(0이면 끔)`, `(봇은 자동 동의)`, 그리고 `+1판.`·`도라 1판.`·`연속 6쯔모.`·`완전 면역.` 같은 서술어 없는 종결.
- `운영 판정 — 관리자가 이 국을 물렸다 (판은 계속됩니다)` → `운영 판정입니다. 관리자가 이 국을 무효로 했습니다. 게임은 계속됩니다.`
- `유국 때 늘 텐파이 취급 — 벌점을 안 내고…` → `유국 때 항상 텐파이로 취급된다. 노텐 벌점을 내지 않고…`

규칙: 조건·예외는 별도 문장으로. 짧은 단위·예시 병기(`(1,000점)`, `(예: 3만을 3통으로)`)는 괄호 유지. 명사 종결은 서술어를 붙인다.
**예외 — 건드리지 않는 괄호**: description 머리말 `(동풍전 1회 · 반장전 2회)`·`(매 국 1회)`·`(상시)`·`(게임 내 1회)`. `augmentBrief.ts:298 splitLead`가 이 괄호를 떼어 배지·조건 줄로 그리고, `description_numbers.test.ts`가 형식을 검사한다. 83종이 같은 규약이다.

### 1-6. 어미 혼용 (약 160곳)
합쇼체 화면 안에 `~다/~한다` 툴팁·뱃지·부제가 섞이고, 튜토리얼 말풍선에 해요체 한 문장이 끼어 있다.
- 결과 화면 부제 `구종구패 — … 국을 물렸다` (제목은 `도중 유국`) → `구종구패입니다. 배패에 요구패와 자패가 9종 이상이었습니다.`
- `봇이 론·쯔모를 하지 않는다 — 판이 끝까지 흐른다` → `봇이 론·쯔모를 하지 않습니다. 국이 끝까지 진행됩니다`

규칙: **화면 단위로 한 문체**. 클라이언트 안내·툴팁·토스트·뱃지·설정 설명은 합쇼체(`~합니다`). 버튼은 명사형(`~하기`). 컷인 부제는 같은 화면 토스트가 합쇼체이므로 합쇼체. 증강 도감은 §2 결정에 따른다.

## 2. 사용자 결정이 필요한 것 3가지

### 2-1. 증강 도감(description/detail/brief/glossary)의 문체
현재 증강 107종의 description·detail, augmentBrief 요약, glossary 풀이, standardAugments, powerTier 비고는 **100% 평서체(`~한다`)**이고 합쇼체는 0건이다. 사용자 예시(리치 BGM 설명)는 로비 안내문이라 합쇼체다.
- **권장(기본값): 도감 계열은 평서체 유지, UI 안내는 합쇼체.** 도감은 사전·카드 텍스트라 평서체가 관례이고, 검증자 6명이 전부 "이 조각만 바꾸면 한 화면 안에서 갈린다"고 판단했다. 부록의 도감 수정안도 평서체로 적었다.
- 대안: 전부 합쇼체. 그러면 F·D·C·I·H 영역 400여 건을 **한 번에** 바꿔야 하고(섞이면 더 나쁘다), 카드 공간이 평균 15~20% 늘어난다.

### 2-2. `**굵게**` 마크다운
도움말·튜토리얼·도감의 `**` 는 `TermText`(App.tsx 9442)가 `<strong>`으로 렌더링해 카드 본문에서는 안 보인다. 그러나 **title 툴팁(App.tsx 26334)과 관리자 티어표에는 별표가 그대로 노출**된다.
- 권장: 도감 description/detail과 powerTier에서는 지운다(툴팁·표 노출). 도움말(HELP_BASICS)·튜토리얼은 강조가 의도된 곳이라 남긴다.

### 2-3. 이모지·아이콘 접두 (🔒 ♻ 🕐 ✦ 📌 🎯 🛡 🤝)
칩·툴팁·버튼 문구 앞에 텍스트로 붙어 있다(App.tsx 18곳 이상). 문구 감수와 별개로 CSS `::before`/aria-hidden span으로 옮기는 게 맞다.
- 권장: 이번 작업에서는 **문장 접두 이모지만 뺀다**(`🎓 튜토리얼 — …`, `✓ 골랐습니다`, `🎲 N초 남았다`). 칩 아이콘(🔒 봉인, ♻ 재장전, 🕐 쿨다운)은 화면 표식이라 남기고 별도 과제로.
