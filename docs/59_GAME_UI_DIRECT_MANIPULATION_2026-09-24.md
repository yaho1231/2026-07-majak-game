- 상대를 골라야 하는데 실제 상대 자리를 누르지 않고 버튼으로 고른다

## 2. 원칙 (이번 감사의 기준)

1. **실물이 판에 보이면 실물을 누른다.** 손패·상대 줄·이름표 pill·내 후로·바닥. 구현은 무장(`ArmMode`) —
   버튼은 «무엇을 할지»만 고르고, «무엇에»는 판에서 고른다.
2. **모달(새 탭)은 판에 안 보이는 것을 보여 줄 때만.** 왕패 안쪽·영상패·패산 순서·보유자에게만 공개된
   상대 손패·변환 뒤 손패 모습. **모달 안에 판의 실물(내 손패 등)을 다시 그리지 않는다.**
   docs/10 §1(2026-07-22) «패를 고르는 증강은 전부 새 탭»을 이 규칙으로 **대체한다**(2026-09-24 사용자 지시, #532).
   그 규약의 목적 — 후보를 텍스트 버튼으로 내지 않고 실제 패 그림으로 고른다 — 은 실물 클릭이 더 직접 채운다.
   남는 모달에는 docs/10의 세부 규약(패 크게·내 손패 정렬·왕패 빈 칸·턴 지나면 닫기)을 그대로 적용한다.
3. **원문 노출 금지.** 내부 id·타입·채널 키는 버튼·툴팁·토스트·기록·aria 어디에도 내지 않는다.
   폴백은 한 경로(`actionLabel`·`augName`) + 개발 모드 `console.warn`, 운영에서는 중립 문구나 생략.
4. **한 번에 버튼 5개 미만을 지향한다.** 같은 종류는 한 버튼으로 접고 실물로 좁힌다(후로·무장해제).
   대상이 추상적인 선택(역 지정)만 버튼이 맞다 — 그때는 세로 목록 대신 격자.
5. **되돌릴 수 없는 선택은 확인 한 번 — 확인창은 새로 만들지 않는다.** 터치의 «두 번 눌러 확정»
   (`tapTwiceToDiscard`)과 안내 줄 [확인]을 재사용한다. 강제 선택(등가교환·미래를 보는 자)은 취소 없이.
6. **이름은 증강 이름 하나.** 버튼·무장 안내·드롭존·관전 칩·컷인 모두 `augActionName`.
   무엇을 하는지는 부제(«승부수 · 리치 취소»)로 붙인다.
7. **빗나감 규칙 하나.** 대상 영역 안의 빗나감은 무시, 대상 영역 밖을 누르면 해제 + 알림. 조용히 풀리지 않는다.
