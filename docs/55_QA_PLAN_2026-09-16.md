### 2-6. «조작·효과 불변»의 정의 — 서버를 고칠 때 깨지면 안 되는 것

- **액션 수락**: `HumanAgent.handleMessage`는 `actionType` 일치 + `JSON.stringify(payload)` **바이트 동일**로만
  받는다(`HumanAgent.ts:1481-1512`). 프롬프트 옵션을 캐시·정규화(키 정렬, undefined 제거)하면 **전 증강 조작이
  INVALID_ACTION**이 된다.
- **뷰**: 클라이언트는 «매 프레임이 완결된 진실»을 전제로 컷인 dedup·재접속 복원·라운드 경계 정리를 한다.
  서버는 델타를 만들지 않는다(`HumanAgent.ts:955-985` 주석). 델타·생략·캐시 재사용 금지.
- **augmentView 채널 이름·값 모양**(40여 종, `PlayerView.ts:640-728`, `App.tsx:18606-18770`)은 계약.
- 골든 해시(§6)가 이 셋 중 코어+봇 경로를 덮고, 서버 골든(§5-A2)이 소켓 프레임·리플레이·DB 행을 덮는다.

6. **스레드풀 경합** — 테이블 100 진행 중 20클라이언트가 초당 비밀번호 login/register: 서버 send→클라 수신 p99 vs loop p99 벌어짐. A/B `UV_THREADPOOL_SIZE=8·16`, deflate off.
7. **프로파일** — `node --cpu-prof` on wsLoadCli 서버(128방): stringify·deflate·SiteDb·StatsStore·EffectRegistry.matching self time.
8. **부팅 이어하기 폭주 (X-3)** — 종반 리플레이 N=20/50/200 + live_games 행으로 서버를 띄워 시작~첫 `/healthz ok` 시간, `restoreLiveGames` 동안 loop max, 동시에 300 로그인의 authOk p99.
9. **폴백 빈도 (X-5)** — 모든 부하 측정에서 `safeDecide` 시간 초과 폴백·`time_pressure` 만료 횟수가 0인지(카운터 C-4). 0이 아니면 그 부하에서 이미 «증강 효과가 달라진» 것이다.
10. **상한 (X-1)** — 구간표를 `MAX_ROOMS`·`MAX_CONNECTIONS` 상한까지 채우고, 상한을 환경변수로 올린 실험 구간(300방/400연결)을 하나 더 잰다.

## 7. 절차 보강 — 머지 사고 재발 방지

- `gh pr merge` 직전에 `git fetch origin && git merge-base --is-ancestor origin/master HEAD` 가 참이어야 한다(최신
  master를 포함). 아니면 `git rebase origin/master` 뒤 게이트 재실행. → CLAUDE.md 3번 게이트에 추가(P-5).
- 머지 되돌림 스캐너(master first-parent 40개): 한 PR이 직전 PR의 파일을 «직전 PR 이전 내용»으로 되돌리면 경고.
  이번 라운드에서 09-01 이후 전수 실행해 M-1·M-2 외에 더 있는지 확인한다.
- 재적용 PR 제목은 «(#원PR) (#재적용PR)» 규약 유지.
