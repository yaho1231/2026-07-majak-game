# 창 크기 자동 맞춤 — 손잡이를 없애고 배치를 창에 맞춘다 (2026-08-24)

사용자 보고: 「인터넷 자체 줌 기본 · 인게임 퍼센트 기본」인 1850×860 창에서 판이 깨진다.
직접 −를 눌러 60%까지 줄이면 깔끔해진다. **그 −/+ 자체를 없애고 어느 창에서든 그 깔끔한
그림이 나오게 해 달라.**

브라우저(크로뮴)로 실제 판을 돌리며 잰 것만 적는다. 재는 도구는
[`qa-lab/layout/probe.js`](../qa-lab/layout/probe.js) — 겹치면 안 되는 그룹끼리 실제 사각형이
얼마나 물리는지, 화면 밖으로 나갔는지, 상자를 넘쳤는지를 한 번에 돌려준다.

## 0. 결론

- 화면의 −/+ 손잡이(`.ui-zoom`)와 Alt +/− 단축키, 저장 키(`majak.uiZoom`)를 전부 없앴다.
- 배율은 이제 **창 하나에서 나온다**: `clamp(min(w/1920, h/1080), 0.75, 2)`.
- 데스크톱 15개 창 크기에서 **겹침 0건**. 고친 것 4건(§2), 남긴 것 3건(§4).

## 1. 왜 깨졌나 — 세로 예산이 전부 고정 px 였다

판의 세로는 이렇게 나뉜다(레이아웃 px, 1850×860 실측):

```
위 띠 76 + 숨통 32 + 아래 띠 267(손패 162 + 오름패 줄 75 + 줄 간격·여백 30)
→ 남는 세로 = H − 375 = 중앙 보드의 세로(--board × 0.9)
→ 중앙 패널 = --board × 0.348
```

세 몫이 **전부 고정 px** 라, 창이 짧아질수록 이들이 세로를 다 먹고 보드만 쪼그라든다.
패널을 강제로 줄여 가며 실측한 임계값:

| 패널(레이아웃 px) | 상태 |
|---|---|
| 276 | 여유. 국 표시·도라·네 방향 점수판이 각자 자리에 있다 |
| ~190 | 빠듯하지만 겹치지 않는다 |
| **152** | **깨진다** — 위쪽 점수판이 "東3국" 위로, 아래쪽이 도라 줄 위로 얹힌다 (= 사용자 보고 화면) |

사람이 −를 누르면 **띠까지 함께 줄어들어** 보드가 살아났다. 즉 사용자가 손으로 반응형을
하고 있었다. 그래서 그 계산을 코드로 옮겼다.

### 2-1. 배율 식

```
scale = clamp(min(창너비 / 1920, 창높이 / 1080), 0.75, 2.0)   ← 소수 둘째 자리로 «버림»
```

`min()` 이라 **가상 뷰포트(= 창 / scale)가 어느 쪽도 1920×1080 아래로 안 내려간다.**
곧 16:9 창은 1366×768이든 4K든 가상 1920×1080으로 수렴해 **같은 그림이 크기만 다르게** 선다.
버림인 이유: 반올림하면 1512×982에서 가상 폭이 1913px 로 6px 모자란다.

하한 0.75는 글자(15px → 11.25px)가 읽히는 선, 상한 2.0은 4K가 원판을 정확히 두 배로
그리는 값이자 WCAG 1.4.4가 요구하는 확대 폭이다.

배율로 다 못 푸는 구간(하한에 걸리는 아주 납작한 창)은 `styles.css` 의
`@container ui (max-height: 900px / 760px)` 안전망이 오름패 줄·손패·숨통을 함께 줄여 받는다.

## 4. 남긴 것

1. **폰 세로: 「대화」 알약(오른쪽 세로 가운데)이 오른쪽 상대 뒷패 한두 장을 덮는다.**
   master 에도 있던 겹침이다(375×812 실측 68%). 알약은 손패 위에 서야 하고 상대 줄은
   화면 세로 가운데에 서야 해서, 둘 다 «그 자리에 있어야 하는» 물건이다 — 배치 자체를
   바꿔야 풀린다.
2. **액션 바(치·펑)가 내 바닥 아래 단을 스친다.** 의도된 거래다 — 실측을 `--own-band` 에
   넣으면 프롬프트가 뜰 때마다 판 전체가 크기를 바꿔 출렁인다(`styles.css --own-band` 주석).
   좁은 폭에서는 `--own-reserve` 가 자리를 비워 둔다. docs/34 §3-1 과 같은 항목.
3. **폰 가로(700×500)의 겹침 9건.** master 는 10건 — 줄었지만 여전히 많다. 이 폭에서는
   네 자리와 구석 위젯이 같은 320px 안에 다 들어와야 해서, 배율로는 못 푼다(docs/34 §3-1).
